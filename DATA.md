# Data: sources, provenance and licensing

Every deal-level number traces to a document. The chain is:

`data/candidates*.csv` (identifiers only) + `data/deal_facts.csv` (sourced values) →
`facts.build` → `data/deals*.csv` (generated; `make facts`) → the study.

| File | What it holds | Source |
| --- | --- | --- |
| `data/candidates.csv`, `data/candidates_asia.csv` | Deals considered: id, name, ticker, region, listing currency, listing type, A+H flag. No numbers. | author |
| `data/deal_facts.csv` | One row per sourced value: offer price, shares after the offering (per class), ADS ratio, listing / prospectus / first-trade dates, exchange rates, revenue and operating profit (SEC filers), sector. Each row has the document URL, the document name and the exact words in it. | SEC EDGAR (424B4/424B1, XBRL company facts), HKEXnews, CNINFO, final Indian prospectuses, issuer and exchange announcements, Federal Reserve H.10 via FRED, Yahoo Finance (first trade date, sector) |
| `data/sources.csv` | Each cited document → its saved text (for the quote checks) and its kind | generated by `tools/build_sources.py` |
| `data/deals.csv`, `data/deals_asia.csv` | The deal tables the study reads (generated from the facts) | generated |
| `data/excluded*.csv` | Deals dropped and why (no prices; documents not retrievable; under $5bn on sourced numbers; scope) | `excluded_manual*.csv` + generated |
| `data/prices.csv` | Monthly adjusted and unadjusted closes for the US + global deals | Yahoo Finance chart API (raw responses in `data/raw/yahoo/`); nine delisted US tickers from the digrin.com snapshot (`data/raw/…snapshot…txt`) |
| `data/benchmarks.csv` | SPY and ACWI adjusted closes, monthly | Yahoo Finance |
| `data/prices_asia.csv`, `data/benchmarks_asia.csv` | Monthly closes for the Asian deals; Nifty BeES, Tracker Fund (2800.HK), CSI 300 ETF/index | Yahoo Finance |
| `data/raw/fred/*.csv` | Daily exchange rates (DEXHKUS, DEXCHUS, DEXINUS, DEXJPUS, DEXUSEU, DEXUSUK) | Federal Reserve H.10 via FRED |
| `data/corrections.csv` | Every hand correction (entry months where the price source starts late; stale snapshot rows) | author |
| `data/corporate_actions.csv` | Splits and bonus issues that explain price adjustments | linked announcements; Yahoo split events |
| `data/fundamentals.csv`, `data/fundamentals_asia.csv` | Valuation pilot inputs, one row per deal with its documents | SEC 424B4 and XBRL; HKEX, CNINFO and Indian prospectuses |
| `data/fundamentals_derivations.csv` | Inputs computed from printed numbers (e.g. EBIT = profit before tax + interest), with the printed numbers | author, checked by `tools/check_fundamentals.py` |
| `data/fundamentals_check.tsv` | For every valuation input: where it is printed, or how it is derived | generated by `make audit` |
| `data/industry_benchmarks.csv`, `data/riskfree.csv` | Industry multiples, margins, WACC by region and year; US 10-year yield | Damodaran (NYU Stern) January archives |
| `data/raw/taxfoundation/` | Statutory corporate tax rates by country and year | Tax Foundation |
| `data/SHA256SUMS` | Checksums of the files above | generated |

## Source documents

The prospectuses and announcements are large (about 2 GB), so they are not stored in git.
`make sources` downloads them from the URLs in `data/sources.csv` and saves their text where
the tests look for it; the quote checks in `tests/test_provenance.py` then run on every fact.
Six documents are marked "remote only": their hosts refuse automated downloads (three CNBC
articles, the Aramco and DEWA final-price announcements, and SoftBank Corp's EDINET filing,
which is an image PDF); open those URLs in a browser to check the quoted words.

Direct-listing reference prices (Spotify, Slack, Palantir, Roblox, Coinbase) are taken from
news reports of the exchange's announcement (CNBC, Renaissance Capital); this build could not
retrieve the exchanges' own notices.

## Licensing

The code and the derived results are open (see LICENSE). **The raw price data belongs to
its providers.** Before you publish this repository, check the terms of use of the price
source. If redistribution is not allowed, delete `data/prices*.csv`, `data/benchmarks*.csv`
and `data/raw/yahoo/`, keep `data/SHA256SUMS` so others can confirm they rebuilt the same
files, and point readers to `make fetch`.

## Adding or correcting a deal

1. Add the identifiers to `data/candidates*.csv`.
2. Add one row per value to `data/deal_facts.csv`: value, unit, document URL, document name,
   and the exact words from the document. Never enter a value that is not printed in a
   document (or computed from printed values, with the computation in `note`).
3. Run `make facts`, `make test`; if headline numbers change, review and run `make golden`.

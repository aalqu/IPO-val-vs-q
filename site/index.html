Check it yourself

  1. Get the code and data: https://github.com/YOUR-NAME/ipo-valuation-vs-quant
  2. Run the tests and rebuild every number on this page: 
    pip install -e ".[test]"
make test        # unit, data-integrity and regression tests
make results     # writes results/results.json and deal_returns.csv
make robustness  # the table above
ipo-study run --universe asia          # Korea, India, Hong Kong, China A
ipo-study valuation --universe asia    # Hong Kong comps/DCF pilot
  3. Rebuild prices from a second source and compare: make crosscheck (downloads from Yahoo Finance).
  4. Change an assumption: ipo-study run --min-mcap 10 --region US --exclude-cohort 2020-21 --bootstrap 2000
  5. Found an error? Open an issue with the deal, the field, the correct value and a source link. Corrections are logged in data/corrections.csv.

Method and limits

  • Universe: 96 listings worth $5bn or more at the offer price, 2010–2025: 79 US (including 5 direct listings) and 17 global. Five deals excluded for lack of monthly prices.
  • Returns: buy-and-hold total return from month-end closes (adjusted for splits and dividends), minus the benchmark's total return over the same months.
  • Traditional valuation (pilot): each IPO's EV/EBITDA, EV/Sales, P/E and dividend yield at the offer price (P/B for financials) against Damodaran's industry multiples for the IPO year and region, and a 10-year DCF with the same rules for every deal. Inputs come from the final prospectus (424B4) and SEC XBRL data; every row links to its filing.
  • Simple screens (all 96 deals): profitability at IPO, price-to-sales against the sample median.
  • Quant rules: reconstructed from published research (long-run underperformance, hot-issue fade, lock-up expiry, post-lock-up momentum). They are not any fund's actual strategy.
  • Limits of the valuation pilot: 19 deals (Porsche excluded for lack of sourceable accounts), so each rule trades only a handful; trailing multiples, not the forward multiples bankers emphasise; basic post-IPO share counts (excluding options and RSUs), which flatter Facebook, Snap, Uber and Airbnb.
  • Not yet verified: for the other 77 deals, offer prices and valuation inputs are approximate and not yet linked to prospectuses. Prices come from one aggregator; the cross-check against a second source has not yet been run.
  • Asia extension (v1.2): 131 listings worth $5bn+ in Korea, India, Hong Kong (including mainland companies' H-shares; A+H dual listings tagged) and mainland China A-shares, with monthly prices from Yahoo Finance and local index benchmarks. Offer prices, sizes and revenues are approximate and not yet tied to prospectuses. Three deals have no price history (Haitong H merged, ESR taken private, Sinovel delisted); dropping delisted Sinovel flatters China A results slightly.
  • Asian valuation pilot (15 deals): Hong Kong (Xiaomi, China Tower, Haidilao, Smoore, Nongfu Spring; HKEX prospectuses), China A (CNNP, Foxconn Industrial Internet, CATL, Mindray, Beijing–Shanghai High-Speed Railway; CNINFO prospectuses, Mindray from its annual report because the prospectus is a scanned image) and India (Coal India, HAL, Zomato, Nykaa, Paytm; prospectuses via SEBI, NSE and the lead managers). Industry benchmarks from Damodaran's China and India files, the Emerging-markets file where a country has fewer than 10 firms in the industry, and the US January 2010 file for Coal India (no earlier India file exists). Korea is not yet valued: DART's search blocks automated access, so it needs an OpenDART API key.
  • Not investment advice. In-sample results, small groups, no costs.
